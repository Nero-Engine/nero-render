# nero-render
Ready-made cloud machine image for video builds: Blender 5.2.2, Node 24 with hyperframes 0.8.138 and Chrome headless shell, ffmpeg, Parakeet speech-to-text and OpenCV face detection. Only free, open-source tools; no project files or keys.
Built by GitHub Actions on every push: `ghcr.io/nero-engine/nero-render:latest`.
